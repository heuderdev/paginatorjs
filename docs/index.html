hr-paginationjs — documentação

Micro-framework de listagens remotas para Joomla 3 / PHP 7.0. Toda a tela é configurada por atributos data-paginationjs-*; JavaScript só é necessário para integrações específicas (eventos e API).

Pagination.js 2.6.0 desenha apenas os botões de página. Requisição, estado, busca, filtros, ordenação, renderização, colunas, preferências e erros pertencem ao hr-paginationjs.

Esta documentação #

Leia no navegador: docs/index.html (ex.: http://localhost/paginatorjs/docs/). Funciona também abrindo o arquivo direto, sem servidor.

As páginas .html são geradas a partir de docs/md/*.md (a fonte). Depois de editar um .md, regere:

npm install
npm run docs

Comandos #

Comando O que faz
npm install Instala as ferramentas de desenvolvimento (esbuild, jsdom, marked). A biblioteca em si não tem dependências npm.
npm run build Gera dist/ (.js, .min.js, .css, .min.css, Pagination.js) e dist/sizes.json.
npm test 35 testes contra src/.
npm run test:dist Os mesmos 35 testes contra dist/hr-paginationjs.min.js.
npm run test:all build + os dois acima.
npm run docs Gera docs/*.html a partir de docs/md/.
npm run pacote build + pacote/hr-paginationjs-<versão>.zip para levar aos projetos.
npm run serve Servidor PHP em http://127.0.0.1:8080/ (exemplos em /exemplos/, docs em /docs/).

Rodar os exemplos #

Com o Laragon: http://localhost/paginatorjs/exemplos/ (o index.php precisa de PHP). Sem o Laragon: npm run serve e abra http://127.0.0.1:8080/exemplos/.
