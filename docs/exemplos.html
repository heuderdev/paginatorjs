Exemplos

Receitas prontas para implementar cada recurso na sua tela. Todo bloco tem o botão Copiar. O código é o que vai na view (HTML + atributos data-paginationjs-*); JavaScript só aparece quando o recurso é específico de JavaScript.

Os blocos ⇄ Requisição gerada mostram o que a tela envia ao endpoint, para você saber o que o controller recebe. Os blocos 👁 Como fica na tela são ilustrações do resultado.

O modelo usado nos exemplos #

Para não repetir, os exemplos usam uma listagem de clientes cujo endpoint devolve estes campos:

JSON Uma linha de data[]
{
    "id": 42,
    "nome": "Ana Silva",
    "email": "ana.silva42@exemplo.com.br",
    "uf": "SP",
    "cidade": "São Paulo",
    "endereco": { "cidade": "São Paulo", "uf": "SP", "cep": "01000-420" },
    "limite_credito": 12500.5,
    "status": "ativo",
    "vip": true,
    "categoria": "varejo",
    "nascimento": "1984-07-12",
    "created_at": "2025-03-14 10:32:00",
    "site": "https://www.exemplo.com.br/cliente/42"
}

E a resposta completa segue o ApiResponseHelper::paginated():

JSON Resposta do endpoint
{
    "success": true,
    "status": "sucesso",
    "mensagem": "Registros carregados.",
    "data": [ { "id": 42, "nome": "Ana Silva" } ],
    "errors": [],

}

Dica: em todos os exemplos, os scripts são carregados uma vez por página, nesta ordem: jQuery → pagination-2.6.0.min.js → hr-paginationjs.min.js. Veja Instalação.
